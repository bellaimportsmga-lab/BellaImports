# Bellas Imports — Configurado

Este projeto já está configurado com o Project URL e a Publishable Key do Supabase.

## Próximos passos

1. No Supabase, vá em Authentication > Users e crie seu usuário administrador.
2. Em Authentication > URL Configuration, adicione a URL do seu GitHub Pages depois que publicar.
3. No GitHub, envie todos os arquivos deste projeto.
4. Ative Settings > Pages > Deploy from a branch > main > /(root).
5. Abra a URL gerada e faça login.

Importante: a Publishable Key pode ficar no frontend. Nunca publique a service_role/secret key.
